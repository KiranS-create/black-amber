# Frontend & UI Engineering Workflow

When working on user interfaces, frontend design, styling, and visual/interactive polish:

## Core Principles
1. **Never ship default, generic AI styling**: Avoid standard gray-box/bootstrap/raw Tailwind templates with purple gradients or low contrast.
2. **Intentional Design Direction**: Before coding, choose a deliberate aesthetic (e.g. Clean Modernist, Industrial Brutalist, High-Density Forensic, Editorial Luxe).
3. **Typography & Hierarchy**: Establish tight typographical scale, crisp contrast ratios, and distinct monospaced accents for technical data.
4. **Motion & Interaction**: Add micro-interactions, responsive hover/focus states, smooth state transitions, and accessible keyboard navigation.
5. **Validation with Playwright**: Use `playwright-cli` or Playwright MCP to verify visual rendering, responsive layouts, and zero-error flows.
